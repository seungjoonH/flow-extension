# 파일 확장자 차단 과제

## 배경

일부 파일은 첨부 시 보안상 문제가 될 수 있습니다. 특히 `exe`, `sh` 등 실행 파일이 서버에 올라가 실행될 위험이 있어, 파일 확장자 차단 기능을 도입합니다.

---

## 기능 요건

### 1. 고정 확장자

| 번호 | 내용 |
|------|------|
| **1-1** | 차단을 자주 하는 확장자를 리스트로 제공한다. 기본값은 **체크 해제(unchecked)** 이다. |
| **1-2** | 고정 확장자를 체크/해제할 때마다 **DB에 저장**한다. 새로고침 후에도 상태가 유지되어야 한다. **고정 확장자는 아래 커스텀 확장자 영역에는 표시하지 않는다.** |

### 2. 커스텀 확장자 입력·추가

| 번호 | 내용 |
|------|------|
| **2-1** | 확장자 입력 **최대 길이: 20자** |
| **2-2** | **추가** 버튼 클릭 시 DB에 저장하고, **하단 영역**에 표시한다. |

### 3. 커스텀 확장자 목록

| 번호 | 내용 |
|------|------|
| **3-1** | 커스텀 확장자는 **최대 200개**까지 추가 가능하다. |
| **3-2** | 확장자 옆 **X** 클릭 시 **DB에서 삭제**한다. |

---

## 과제 제출 시 추가 서술

위 요건 외에 **어떤 점을 고려했는지** 적어 제출한다.

**예시**

- 커스텀 확장자 **중복 방지** (예: `sh`를 추가한 뒤 다시 `sh`를 추가하려 할 때의 처리)
